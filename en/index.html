Where do I start
with Git?

Install VS Code and Git, connect GitHub, learn the basic commands, and put your website online. Short steps, easy to follow.

Let's start

1 Install Visual Studio Code

VS Code is a free code editor with Git built in. We use it for the whole guide.

  1. Go to code.visualstudio.com and click Download.
  2. Run the installer. On the Select Additional Tasks step, tick Add to PATH and Add "Open with Code".
  3. Open VS Code. To check, open any terminal and run the command below.
code --version

Later, to open a folder in VS Code, go to that folder and run:

code .

2 Install Git

  1. Go to git-scm.com/downloads and download the version for your system.
  2. Run the installer and click Next with the default options. The Windows version includes Git Credential Manager, used in part 3.
  3. Open a new terminal (or press Ctrl+` in VS Code) and check.
git --version

Set your identity (one time)

Git writes your name and email in every commit. Use your GitHub account email so commits link to you.

terminal

git --version

git version 2.47.0.windows.1

git config --global user.name "Your Name"

git config --global user.email "you@example.com"

git config --global --list

user.name=Your Name

user.email=you@example.com

3 Connect GitHub to Git

Git runs on your computer. GitHub stores your repos online. To push code, your computer must prove you own the account.

Your PC
(Git)
GitHub
1. Git sends a push request 2. GitHub asks: who are you? 3. You sign in, code is saved

Step 1: Create an account and a repo

  1. Sign up at github.com/signup.
  2. Click New repository, set a name, choose Public, click Create repository. Copy the repo URL.

Step 2: Choose how to sign in

Option A – HTTPS + Git Credential Manager (easiest, recommended). No extra setup. On your first push, a browser window opens. Sign in to GitHub and you are done. Your login is stored safely on your computer.

git remote add origin https://github.com/YOUR-NAME/YOUR-REPO.git
git push -u origin main

Option B – SSH key. For people who do not want to sign in again, or who use many computers.

ssh-keygen -t ed25519 -C "you@example.com"
cat ~/.ssh/id_ed25519.pub
  1. Copy the content of the .pub file (the public key).
  2. GitHub → Settings → SSH and GPG keys → New SSH key → paste it.
  3. Test the connection, then use the SSH form of the URL.
ssh -T git@github.com
git remote add origin git@github.com:YOUR-NAME/YOUR-REPO.git
git push -u origin main
Never paste a password, token, or private key (id_ed25519, the file without .pub) into a command, a code file, or a chat. GitHub also does not accept your normal password for Git over HTTPS.

4 Work with Git and GitHub in VS Code

VS Code does most Git work with the mouse. No commands needed.

Sign in to GitHub

Click the Accounts icon (bottom left) → Sign in with GitHub → allow access in the browser.

Get a repo, or put a folder on GitHub

  • Existing repo: Ctrl+Shift+P → Git: Clone → paste the URL → pick a folder.
  • New folder: open the folder → Source Control tab → Publish to GitHub. VS Code creates the repo and pushes it.

Daily workflow

Open Source Control with Ctrl+Shift+G. Watch the demo below:

  1. Edit a file. It appears under Changes.
  2. Click + to move it to Staged Changes (same as git add).
  3. Type a message using the rules in part 6, then click Commit.
  4. Click Sync Changes to send it to GitHub (same as git push).

5 Basic Git commands

Git moves code through 4 areas. Each command pushes code to the next area:

Working folder
git add
Staging
git commit
Local repo
git push
GitHub
terminal

git init

Initialized empty Git repository in .git/

git add index.html

git commit -m "feat: add homepage"

[main (root-commit) a1b2c3d] feat: add homepage

1 file changed, 12 insertions(+)

git push -u origin main

branch 'main' set up to track 'origin/main'.

git init

Turn the current folder into a Git repo.

git clone <url>

Download a repo from GitHub.

git status

See which files changed or are staged.

git add <file>

Move a file to the staging area.

git commit -m "msg"

Save a snapshot (commit) with a message.

git diff

See exactly which lines changed.

git log --oneline

Show commit history, one line each.

git branch

List or create branches.

git switch <branch>

Move to another branch.

git merge <branch>

Merge a branch into the current one.

git pull

Get new commits from GitHub.

git push

Send your commits to GitHub.

git remote -v

Show the remote repo you connect to.

Good habit: run git status before every commit, and git pull before you start work.

6 Commit rules

Use the Conventional Commits standard. History is easy to read, bugs are easy to find, changelogs are easy to make.

type(scope): short description

scope is optional. Example: feat(nav): add language switch.

typeUse when
featYou add a new feature
fixYou fix a bug
docsYou change docs only
styleFormatting or CSS change, no logic change
refactorYou rewrite code, behavior stays the same
testYou add or fix tests
choreSmall tasks: config, dependencies

Rules

  • Keep the description short, 50 characters at most, no period at the end.
  • Use the imperative mood: add, not added.
  • One commit, one job. Do not mix a bug fix and a new feature.
  • Commit small and often. Each commit should work.
  • Run git add only for the files you need. Avoid a blind git add ., it picks up junk files.
  • Never commit secrets: .env, keys, tokens. Put them in .gitignore.

✔ Good

  • feat: add contact form
  • fix(nav): close menu on click
  • docs: update install steps

✘ Not good

  • update
  • fixed stuff.
  • add form and fix menu and change colors

7 Deploy a static site to GitHub Pages

GitHub Pages hosts HTML/CSS/JS pages for free. You only need a public repo.

  1. Put index.html in the root folder of the repo. In your HTML use relative paths (style.css, not /style.css), because the site lives under /your-repo/.
  2. Commit and push to the main branch.
  3. On GitHub: Settings → Pages.
  4. Under Source choose Deploy from a branch. Under Branch choose main and / (root), then click Save.
  5. Wait 1–2 minutes. The site address shows at the top of the Pages screen.
git add index.html style.css script.js
git commit -m "feat: add tutorial site"
git push origin main

The address looks like this:

https://YOUR-NAME.github.io/YOUR-REPO/
Each git push to main updates the site in about one minute. If you do not see the change, press Ctrl+F5 to clear the cache.
