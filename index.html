Cài VS Code và Git, kết nối GitHub, nắm lệnh cơ bản và đưa web của bạn lên mạng. Đọc nhanh, làm theo là chạy.

Bắt đầu thôi

1 Cài đặt Visual Studio Code

VS Code là trình soạn code miễn phí, có sẵn giao diện Git. Ta sẽ dùng nó cho cả hướng dẫn.

  1. Vào code.visualstudio.com và bấm Download.
  2. Chạy file cài đặt. Ở bước Select Additional Tasks, tick Add to PATH và Add "Open with Code".
  3. Mở VS Code. Kiểm tra bằng cách mở terminal bất kỳ và gõ lệnh dưới.
code --version

Sau này, để mở một thư mục bằng VS Code, đứng trong thư mục đó và gõ:

code .

2 Cài đặt Git

  1. Vào git-scm.com/downloads, tải bản cho hệ điều hành của bạn.
  2. Chạy file cài đặt, cứ bấm Next với các tuỳ chọn mặc định. Bản Windows đã gồm Git Credential Manager, dùng ở phần 3.
  3. Mở terminal mới (hoặc Ctrl+` trong VS Code) và kiểm tra.
git --version

Khai báo danh tính (làm một lần)

Git ghi tên và email vào mỗi commit. Dùng email của tài khoản GitHub để commit gắn đúng người.

terminal

git --version

git version 2.47.0.windows.1

git config --global user.name "Ten Cua Ban"

git config --global user.email "ban@example.com"

git config --global --list

user.name=Ten Cua Ban

user.email=ban@example.com

3 Kết nối GitHub với Git

Git chạy trên máy bạn. GitHub là nơi lưu repo trên mạng. Muốn đẩy code lên, máy bạn phải chứng minh mình là chủ tài khoản.

Máy bạn
(Git)
GitHub
1. Git gửi yêu cầu push 2. GitHub hỏi: bạn là ai? 3. Bạn xác thực, code được lưu

Bước 1: Tạo tài khoản và repo

  1. Đăng ký tại github.com/signup.
  2. Bấm New repository, đặt tên, chọn Public, bấm Create repository. Chép URL repo.

Bước 2: Chọn cách xác thực

Cách A – HTTPS + Git Credential Manager (dễ nhất, nên chọn). Không cần cấu hình gì thêm. Lần push đầu tiên, một cửa sổ trình duyệt mở ra, bạn đăng nhập GitHub, xong. Thông tin được lưu an toàn trong máy.

git remote add origin https://github.com/TEN-BAN/TEN-REPO.git
git push -u origin main

Cách B – SSH key. Dành cho ai không muốn đăng nhập lại, hoặc dùng nhiều máy.

ssh-keygen -t ed25519 -C "ban@example.com"
cat ~/.ssh/id_ed25519.pub
  1. Chép nội dung file .pub (khoá công khai).
  2. GitHub → Settings → SSH and GPG keys → New SSH key → dán vào.
  3. Thử kết nối, rồi dùng URL dạng SSH.
ssh -T git@github.com
git remote add origin git@github.com:TEN-BAN/TEN-REPO.git
git push -u origin main
Không bao giờ dán mật khẩu, token hoặc khoá riêng (id_ed25519, không có .pub) vào lệnh, file code hay chat. GitHub cũng không nhận mật khẩu thường cho Git qua HTTPS.

4 Làm việc với Git và GitHub trong VS Code

VS Code làm được hầu hết việc Git bằng chuột, không cần gõ lệnh.

Đăng nhập GitHub

Bấm biểu tượng Accounts (góc dưới bên trái) → Sign in with GitHub → cho phép trong trình duyệt.

Lấy repo về máy hoặc đưa thư mục lên GitHub

  • Có repo sẵn: Ctrl+Shift+P → Git: Clone → dán URL → chọn thư mục.
  • Thư mục mới: mở thư mục → tab Source Control → Publish to GitHub. VS Code tạo repo và push luôn.

Quy trình hằng ngày

Mở Source Control bằng Ctrl+Shift+G. Xem demo bên dưới:

  1. Sửa file, nó hiện ở mục Changes.
  2. Bấm + để đưa vào Staged Changes (tương đương git add).
  3. Gõ message theo quy tắc ở phần 6, bấm Commit.
  4. Bấm Sync Changes để đẩy lên GitHub (tương đương git push).

Mẹo: mở terminal ngay trong VS Code bằng Ctrl+`. Lệnh Git gõ ở đó chạy y như terminal ngoài.

5 Các lệnh Git cơ bản

Git chuyển code qua 4 vùng. Mỗi lệnh đẩy code sang vùng kế tiếp:

Thư mục làm việc

Staging

Biến thư mục hiện tại thành repo Git.

git clone <url>

Tải repo từ GitHub về máy.

git status

Xem file nào đã sửa, đã staged.

git add <file>

Đưa file vào vùng staging.

git commit -m "msg"

Lưu ảnh chụp (commit) kèm lời nhắn.

git diff

Xem chính xác dòng nào đã đổi.

git log --oneline

Xem lịch sử commit gọn một dòng.

git branch

Liệt kê hoặc tạo nhánh.

git switch <nhánh>

Chuyển sang nhánh khác.

git merge <nhánh>

Gộp nhánh vào nhánh hiện tại.

git pull

Lấy commit mới từ GitHub về máy.

git push

Đẩy commit của bạn lên GitHub.

git remote -v

Xem repo từ xa đang nối tới.

Thói quen tốt: chạy git status trước mỗi lần commit, và git pull trước khi bắt đầu làm việc.

6 Quy tắc commit

Dùng chuẩn Conventional Commits. Lịch sử dễ đọc, dễ tìm lỗi, dễ làm changelog.

type(scope): mô tả ngắn

scope không bắt buộc. Ví dụ: feat(nav): add language switch.

typeDùng khi
featThêm tính năng mới
fixSửa lỗi
docsChỉ đổi tài liệu
styleĐổi định dạng, CSS, không đổi logic
refactorViết lại code, không đổi hành vi
testThêm hoặc sửa test
choreViệc vặt: cấu hình, dependency

Quy tắc

  • Mô tả ngắn, tối đa 50 ký tự, không dấu chấm cuối.
  • Dùng thể mệnh lệnh: add, không phải added.
  • Một commit, một việc. Đừng gộp sửa lỗi và thêm tính năng.
  • Commit nhỏ, thường xuyên. Mỗi commit nên chạy được.
  • Chỉ git add đúng file cần. Tránh git add . bừa, nó kéo cả file rác.
  • Không commit file bí mật: .env, khoá, token. Thêm chúng vào .gitignore.

✔ Tốt

  • feat: add contact form
  • fix(nav): close menu on click
  • docs: update install steps

✘ Chưa tốt

  • update
  • fixed stuff.
  • add form and fix menu and change colors

7 Deploy web tĩnh lên GitHub Pages

GitHub Pages host miễn phí các trang HTML/CSS/JS. Chỉ cần repo public.

  1. Đặt index.html ở thư mục gốc của repo. Trong HTML, dùng đường dẫn tương đối (style.css, không phải /style.css), vì site nằm dưới /ten-repo/.
  2. Commit và push lên nhánh main.
  3. Trên GitHub: Settings → Pages.
  4. Mục Source chọn Deploy from a branch. Mục Branch chọn main và / (root), bấm Save.
  5. Đợi 1–2 phút. Địa chỉ site hiện ở đầu trang Pages.
git add index.html style.css script.js
git commit -m "feat: add tutorial site"
git push origin main

Địa chỉ có dạng:

https://TEN-BAN.github.io/TEN-REPO/
Mỗi lần git push lên main, GitHub tự cập nhật site sau khoảng một phút. Nếu chưa thấy đổi, thử Ctrl+F5 để xoá cache.
